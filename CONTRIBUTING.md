# Contributing

Read SETUP.md. Keep changes focused on the current milestone.
Keep interchange independent of Android and persistence. Add behavioral tests for
imports, round trips, and migrations. Never use destructive Room migration fallback.
Do not commit personal data, keys, tokens, or identifying fixtures. No paid APIs,
accounts or analytics. The only automatic network request is the user-controllable
GitHub update check; never attach workouts, meals, photos, backup contents, IDs or
device identifiers to it. Pin dependencies in the catalog.

Public contribution terms await selection of an open-source license.
